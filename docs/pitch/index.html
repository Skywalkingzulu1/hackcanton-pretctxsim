The problem

01Blind signing drains wallets — and enterprises can't use the fix

Users sign what they can't read

Wallet-drainer phishing stole $494M in 2024 (+67% YoY, 332k addresses). One malicious approve() or EIP-7702 delegation empties a wallet.

Existing simulation leaks intent

Blockaid, Tenderly, Alchemy simulate on their servers — your transaction data goes to a third party. (Alchemy's sim APIs were deprecated Sept 2026.) Enterprises, treasuries and agents can't accept that.

The gap: there is no local, open-source, drop-in simulation layer. Every option is cloud-hosted, wallet-locked, or dead.
The solution

02PreTxSim: a security proxy at the signing moment

Point any wallet, bot, or AI agent at http://127.0.0.1:8545. PreTxSim intercepts eth_sendTransaction, simulates it locally with revm, briefs you, and gates broadcast behind your confirmation.

Under the hood

04RiskInspector: structural, deterministic, fast

Control-flow flags

  • DELEGATECALL opcode counter
  • SELFDESTRUCT tripwire
  • Storage slots written

Value-flow diffs

  • Balance changes + deltas
  • Token transfers (logs)
  • Allowance changes

Post-Pectra risks

  • EIP-7702 delegation designator parsing
  • Delegated-EOA detection at load
  • Emitted-log capture
Deterministic checks do the provable work; the local LLM only advises. Separation of powers — the Vergil/ONCHOR winning pattern.
Privacy architecture + DevSecOps

05Air-gapped by design, CI-ready by flag

Nothing leaves the machine

  • Simulation in-process via revm (Rust)
  • AI brief from local Ollama (smollm2) — offline
  • Only state reads hit your chosen RPC; keys never broadcast until you say so

--ci mode for pipelines

  • Pipe a tx in → structured JSON report out
  • Exit 1 on BLOCK findings — fails the build
  • Shift-left Web3 security for contract CI/CD
$ cat tx.json | ./pretxsim_poc --ci

Why HackCanton · Enterprise Privacy & Contract Logic

06Privacy isn't a feature here. It's the architecture.

Enterprise privacy

Transaction intent is market-sensitive. PreTxSim never exposes it to a vendor cloud — simulation, AI briefing, and the gate all run inside your perimeter. Auditable, self-hostable, open-source.

Contract-logic verification

Every call is rehearsed against live state before signing: condition outcomes, balance deltas, gas, side effects. The same engine validates multisig proposals, agent payments, and event-driven executions.

One command to evaluate: docker compose up → proxy + Ollama. No accounts, no keys, no setup friction for judges.
