## ESP Submission

- **Portal**: https://esp.ethereum.foundation/form-direct/apply
- **Required Fields**:
  - Contact information (first/last name, email, company, website)
  - Applicant profile (bio, team experience)
  - Budget request ($20,000 USD)
  - Project name, summary, repo link
  - Domain (Developer Tooling)
  - Output type (Tooling/Library)
  - Project structure (timeline + milestones)
  - Sustainability plan
  - Funding status (no other funding)
  - Problem being solved
  - Measured impact
  - Success metrics
  - Ecosystem fit
  - Community feedback
  - Open source license (MIT)
  - Payment acknowledgement
  - PDF proposal (optional but recommended)
- **Application Content**: See `funding/esp_application_pretxsim.md` and `funding/esp_application_pretxsim.pdf`
